# Maps Listing Research — Telegram-бот

Сбор **публичных** карточек Google Maps / Places. Город, категорию и число карточек админ вводит вручную в боте. Демо-пресеты отключены.

Бот не пишет бизнесам и владельцам. Рассылок нет. Веб-панели нет.

Запускайте на своей машине, не на Cursor cloud VM.

## Что делает

- Старт / стоп задачи: город текстом → категория текстом (можно «все») → число карточек
- Геокод города, text search заведений (не карточка самого города), страницы Places до запрошенного числа
- Сбор публичных полей карточки (название, категория, адрес, телефон/сайт если они есть на карточке, рейтинг, число фото, URL Maps)
- Классификация: **есть публичная карточка Maps** / **неполная** / **нет карточки**
- Прогресс и результаты в чате
- По окончании задачи автору уходит сообщение: готово/ошибка, город, число карточек
- Выгрузка CSV публичных полей (UTF-8 с BOM) — только реально собранные строки
- Супер-админ одобряет других пользователей Telegram в самом боте

## Стек

- Python 3.12, aiogram 3, SQLite (WAL)
- Официальный **Google Places API (New)** — без ключа задача отклоняется, демо-данных нет

## Как запустить

На своей машине:

```bash
cd maps-lead-research
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# TELEGRAM_BOT_TOKEN, TELEGRAM_ADMIN_IDS, GOOGLE_PLACES_API_KEY
python -m app.bot_app
```

Без токена процесс не ходит в Telegram: пишет предупреждение и остаётся idle.

Опционально Docker:

```bash
cp .env.example .env
docker compose up --build
```

Тесты:

```bash
PYTHONPATH=. pytest -q
```

## Команды бота

Супер-админ — Telegram id `5320066517` (плюс id из `TELEGRAM_ADMIN_IDS`). Остальным нужен апрув супер-админа.

| Команда | Действие |
|---|---|
| `/start` | Меню; неизвестный пользователь создаёт заявку |
| `/help` | Справка и границы |
| `/new` | Город → категория → число карточек |
| `/progress` | Статус последних задач |
| `/stop` | Остановить активную задачу |
| `/listings` | Листать реальные карточки |
| `/export` | Скачать CSV публичных полей (UTF-8 с BOM) |
| `/users` | Только супер-админ: заявки и одобрение |

Одобрение: супер-админ получает заявку с кнопками и может открыть `/users`.

## CSV

Файл в UTF-8 **с BOM**, чтобы Excel на Windows открывал кириллицу. В выгрузке только публичные поля и только строки `source=google_places`. Демо/`cid-demo-*`/фикстуры отфильтрованы.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота; пусто = процесс idle, без polling |
| `TELEGRAM_ADMIN_IDS` | Дополнительные супер-админы через запятую |
| `SUPER_ADMIN_TELEGRAM_ID` | Супер-админ (по умолчанию `5320066517`) |
| `DATABASE_PATH` | SQLite-файл (по умолчанию `./data/app.db`) |
| `GOOGLE_PLACES_API_KEY` | Places API (New). Пусто = отказ задачи, не демо |
| `OPENAI_API_KEY` | Опциональные заметки о полноте |
| `JOB_REQUEST_DELAY_SECONDS` | Пауза между карточками |
| `JOB_MAX_RESULTS` | Запасной лимит, если в задаче не задано число |
| `JOB_MAX_PAGES` | Минимум страниц Places; фактическое число растёт с лимитом |

В Google Cloud включите Places API (New) Text Search. Коллектор вызывает только `places:searchText` с field mask публичных полей.

## Лимиты

Одновременно выполняется одна задача. Число карточек — от 1 до 200, его вводят в `/new`. Между карточками пауза `JOB_REQUEST_DELAY_SECONDS`. На HTTP `429` — одна пауза 15 секунд.

Корень проекта: этот каталог (`maps-lead-research`).
